# Speedtest CLI

Консольный скрипт на Python для замера скорости скачивания по заданному URL.

Скрипт последовательно выполняет 10 HTTP/HTTPS-запросов к указанному ресурсу (например, тяжёлой картинке или файлу), дожидается полного получения каждого ответа, вычисляет среднее время запроса, общий объём скачанных данных и итоговую скорость скачивания.

## Требования и установка

- Python 3.11 или выше
- [httpx](https://www.python-httpx.org/)

Установка зависимостей через `uv`:

```bash
uv sync
```

Или через `pip`:

```bash
pip install httpx
```

## Запуск

Базовый запуск (10 последовательных запросов):

```bash
uv run python speedtest.py <URL>
```

Или из активированного виртуального окружения:

```bash
python speedtest.py <URL>
```

Пример:

```bash
uv run python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

### Дополнительные параметры

```text
positional arguments:
  url                   URL ресурса для скачивания (http:// или https://)

options:
  -h, --help            показать справку и выйти
  -n, --requests N      количество последовательных запросов (по умолчанию: 10)
  -t, --timeout SEC     таймаут одного запроса в секундах (по умолчанию: 30.0)
  -A, --user-agent UA   значение заголовка User-Agent
```

Пример с указанием количества запросов и таймаута:

```bash
python speedtest.py https://example.com/large-image.png -n 5 -t 15
```
